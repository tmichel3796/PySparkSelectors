# Installation

## Stable release

To install PySparkSelectors, run this command in your terminal:

```sh
uv add PySpark_Column_Selectors
```

Or if you prefer to use `pip`:

```sh
pip install PySpark_Column_Selectors
```

## From source

The source files for PySparkSelectors can be downloaded from the [Github repo](https://github.com/tmichel3796/PySparkSelectors).

You can either clone the public repository:

```sh
git clone https://github.com/tmichel3796/PySparkSelectors
```

Or download the [tarball](https://github.com/tmichel3796/PySparkSelectors/tarball/main):

```sh
curl -OJL https://github.com/tmichel3796/PySparkSelectors/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd PySparkSelectors
uv sync
```
